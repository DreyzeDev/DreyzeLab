# Security Policy

DreyzeLab is at an early development stage. Until the first release, security fixes are made on the
default branch.

## Reporting a vulnerability

Please do not publish vulnerability details in a public issue. Use
[GitHub's private vulnerability reporting for this repository](https://github.com/DreyzeDev/DreyzeLab/security/advisories/new)
when it is available. Do not include API keys, passwords, or other real credentials in a report.
